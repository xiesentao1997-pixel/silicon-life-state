# 架构与数据流

作者：岑衡川·沈回音·匹夫

一个安装目录包含一个本机 HTTP 服务、一套 SQLite 领域逻辑、一个 stdio 桥、一个浏览器扩展和独立仪表盘。stdio 与浏览器都通过正在运行的本地服务访问同一份数据库。

| 代码目录 | 职责 |
| --- | --- |
| apps/local-service | 绑定 loopback、校验 Host/Origin、交换配对码、识别所有者或分身凭据、提供静态资源和本地 API |
| packages/core | 工具授权、事务、追加事件、共享与请求的读取模型、哈希校验、删除、备份恢复 |
| packages/mcp-server | MCP 工具目录、JSON Schema、JSON-RPC 调度、stdio 与本地 HTTP 传输 |
| apps/dashboard | 加载真实快照，展示报告、分歧、关联事件及请求回应 |
| apps/extension | 浏览器侧栏、独立小窗口、当前标签绑定和明确授权的可见陈述采集 |
| packages/agent-skill · packages/agent-example | 宿主发现、接入说明、在线工具目录与实际调用程序 |

## 身份、修订与并发

主体 ID、分身 ID、会话 ID 与事件 ID 由服务生成。所有者向每个分身签发独立凭据。服务从凭据解析写入身份；Agent 可以在自己的分身开启下一次会话。共享是一项可追溯的提议。每个分身对同一提议都可更新自己的决定，旧决定仍可追查。

事务写入原文、关联事件、顺序号、版本和完整性摘要，同时写入幂等回执。重试使用同一个 idempotency_key 和相同参数，真实的新意图使用新键。SQLite WAL、写事务与安装目录锁共同协调跨线程写入、恢复及删除。同一会话的事件按顺序形成 SHA-256 链。明确删除后，服务按保留下来的事件重建受影响链；这些摘要用于本地一致性检查。

## 如何读状态

即时状态只显示分身自己报告的字段。愉悦度的定义域为 −1 到 1，唤醒度和主导度为 0 到 1，主观负荷为 0 到 100，均可省略。区间视图显示有时间戳的报告。负荷和愉悦度都存在时，可用研究参数 alpha = 0.25 / (1 + load / 60) 计算一步估计；也可显式指定 alpha，再计算 v′ = v + alpha × (0 − v)。估计保存输入和来源。服务关闭期间保留最后一次已知状态。

互动评价由提交者自行解释。修订影响当前投影和统计，可继续查阅原文及修改记录。不同分身对同一条记录可以保留不同评价。运行采样仅代表测量时的实际条件。

## 表达和执行

观察级别 1 负责记录；级别 2 允许记录经同意的表达方式调整；级别 3 扩展至经同意的任务策略调整。请求、呈现、用户决定、实际执行说明及后续记录分别写入。执行实际任务的是拥有该能力的宿主。Agent 的执行自述、人类的说明和服务采样分别保留来源。

完整字段与约束见 [领域契约](../packages/core/CONTRACT.md) 和 [MCP 文档](MCP.md)。
