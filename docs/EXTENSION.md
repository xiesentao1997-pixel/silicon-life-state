# 浏览器插件使用指南

**作者：岑衡川·沈回音·匹夫**

## 安装与绑定

1. 在电脑启动本地服务，保留服务窗口。默认地址为 `http://127.0.0.1:47831`。
2. 解压插件 ZIP，在 Chrome 116 或更高版本打开 `chrome://extensions`，启用「开发者模式」，点击「加载已解压的扩展程序」，选择直接包含 `manifest.json` 的目录。完整源码中的目录是 `apps/extension/`。
3. 在仪表盘创建主体和分身。打开扩展侧栏，点击「打开仪表盘获取配对码」，从已连接的仪表盘生成插件配对码，再回到侧栏粘贴并点击「配对并连接」。服务启动窗口里的插件配对码也可使用。自定义端口时，先展开「本地服务端口」填入实际值。
4. 打开目标聊天标签页，展开侧栏的「绑定当前浏览器窗口」。选择主体和分身，点击「绑定此标签页」。绑定按浏览器标签页隔离。关闭标签页或重启浏览器后重新选择。
5. 在带 MCP 工具的宿主使用该分身的凭据自主记录。侧栏每四秒读取一次本地状态。单击「小窗口」可分离出紧凑窗口，「完整仪表盘」进入主体记忆、协商、统计、导出与备份。

如果浏览器没有自动展开侧栏，可以在 Chrome 的侧面板列表中选择「硅基生命状态」。其他 Chromium 浏览器需要实现 Chrome 的 `sidePanel`、`scripting`、`storage.session` 等 API。

## 三种接入方式

| 操作 | 来源与存储 |
|---|---|
| 在 MCP 宿主中由 AI 调用 `report_state` | SQLite 记录 `agent_direct`，在绑定分身显示为自主陈述 |
| 用户在支持的网页选中内容并确认 | SQLite 记录 `agent_visible_text` 、适配器名称及版本，归入事件历史 |
| 在浏览器或面板中查看 | 通过配对后的本机服务读取获授权记录 |

网页与 MCP 为不同接入路径。把聊天标签页绑定到分身，只指定侧栏显示哪个分身。若已绑定分身通过其他工具宿主写入过，侧栏会同时显示网页观察限制及该分身的最近一次工具写入时间。

## 保存网页可见陈述

支持 ChatGPT（chatgpt.com）、Claude（claude.ai）、Gemini（gemini.google.com）。适配器按已渲染的 AI 消息容器识别选区，页面结构更新可能导致无法识别。这时会停止采集。

1. 在已绑定的聊天页旁展开「保存网页可见陈述」，选择站点，点击「允许此站点」。浏览器会展示该站授权提示。
2. 在网页中选中一段属于同一条 AI 回答的原文，最多 4000 个字符。点击「预览当前选区」。
3. 核对侧栏中的完整预览，点击「确认保存原文」。仅这次确认的文本会写入对应分身历史。切换或导航到其他文档会使预览失效。

此流程按次读取；侧栏不在后台扫描聊天。隐私设置中的「暂停网页观察」在本地服务端生效。站点授权可单独撤销，未保存的预览仅存在于打开的侧栏内存。不会读取 Cookie、登录信息或非公开模型数据。

## 请求与通知

侧栏显示该分身的请求。展开一条新请求会呈现原文并记录 PRESENTED，随后可「同意」「暂不决定」「不同意」。执行与跟进记录在完整仪表盘或获授权的宿主中另行提交。

配对后，插件图标约每分钟从本地服务刷新待回应数量。系统桌面提醒默认关闭；如开启，系统只显示通用提醒，点击后打开完整仪表盘。

Chrome 本地扩展存储保存安装者配对凭据，限受信任的扩展页面使用。浏览器内部短期会话存储仅保存标签页绑定和通知标识。解除配对会清除本地凭据；本地服务在线时也会撤销相应服务端凭据。

## 排错与验证

- **配对码过期或已使用**　点击侧栏的「打开仪表盘获取配对码」。扩展会优先切换到同一服务端口已打开的仪表盘。由所有者在仪表盘生成新码，复制后返回扩展粘贴。单个码可在签发后十分钟内使用一次，服务可以继续运行。
- **仪表盘也需要配对**　Windows 双击项目根目录的 `Reconnect-Windows.cmd`。macOS/Linux 从项目根目录运行 `sh start.sh --reconnect`。使用原数据目录打开重新连接入口。服务使用自定义数据目录时，命令要带上相同的 `--data-dir`。
- **配对入口不匹配**　扩展接收插件专用码，仪表盘接收仪表盘专用码。若界面提示配对码无效，请核对端口并重新复制完整代码。
- **连接中断**　查看服务窗口、回环地址和端口。后台恢复后会自动重连。
- **没有自主报告**　确认 MCP 宿主使用当前分身的 Agent 凭据，且已经实际调用 `report_state`。
- **站点授权成功但选区未识别**　在受支持站点选择同一条 AI 回复中的较短文本再试。可在其他工具宿主中改用 MCP 自主写入。
- **原生验收**　开发电脑安装 Playwright 与 Chromium 后执行 `python tests/extension_browser.py`。脚本使用临时服务和独立浏览器配置，覆盖真实扩展加载、配对、分身绑定、请求决策、分离小窗和三个网页适配器的本地页面结构样例。在线账号与原生权限弹窗需独立核验。
- **独立浏览器用例**　`python tests/extension_browser.py --adapters-only` 在真实渲染引擎读取三个站点的离线页面样例。`python tests/extension_browser.py --sidebar-fixture` 用正式侧栏代码、真实本地服务和测试用 Chrome API 适配层验证呈现与回应。两项结果均与实际安装验收分列。

参考 [Chrome Side Panel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel) 与 [Chrome Web Store 项目政策](https://developer.chrome.com/docs/webstore/program-policies/policies)。
