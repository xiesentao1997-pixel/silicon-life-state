# 隐私、权限与数据生命周期

作者：岑衡川·沈回音

## 记录从哪里来

服务默认监听本机回环地址。日常使用没有广告、分析 SDK、第三方字体或云数据库。软件只处理主动提交和明确授权的内容。服务和扩展不读取登录 Cookie、模型隐藏推理或平台 API Key，也不据此联结身份。每个安装者可以绑定多个主体和多个分身。

网页侧使用站点的可选权限，用户选择可见的助手原文，核对预览后提交。用户可以暂停观察、撤销站点权限或解除绑定。Agent 的原话、网页文本、运行采样、模型估计及用户说明各自标明产生方式。到了外部 AI 宿主，其工具输入、结果和对话是否发送给模型供应商由该宿主决定；安装本软件本身无需向供应商发送对话。

## 谁可以读取

配对的本机所有者能管理本安装中的主体。分身凭据只允许写入本分身、读取自己的历史、读取本主体被明确共享的报告，以及作出自己的继承决定。请为每个窗口分发独立凭据。操作系统账户能够直接访问本地数据文件；SQLite 文件和导出内容以明文保存。系统账户权限与磁盘加密由设备所有者控制。

## 备份、恢复与删除

- 在「导出与备份」下载包含原文、关系、UTC 时间和哈希的 JSON。导出省略访问凭据。它适合查阅、分析与迁移开发，恢复入口使用本服务创建的受管备份。
- 本机备份保存在数据目录，恢复前校验受管备份、SQLite 与事件链。恢复将回到所选快照；已经撤销的分身授权不会重新生效。若活动数据库已损坏，可从启动命令离线恢复，并重新签发需要的分身凭据。请同时保存安装数据目录中的签发密钥；本机恢复依赖它。
- 删除会话或主体会删除所选原始内容，以及依赖被删事件的关联记录、重放回执，并清除本程序管理的备份快照。其他分身在无关联事件中独立写下的相同文字保留其自身的归属。删除全部数据会移除主体、分身、事件和受管备份。浏览器设置和当前配对的生命周期见安装指南。
- 删除完成后，数据库执行安全删除、日志收缩与整理。用户手动下载的导出、另行复制的数据目录、磁盘快照、浏览器下载历史、外部宿主已接收的工具结果和系统备份，应分别在相应位置管理。程序不能验证底层 SSD 每个物理块的擦除。
- 若要完全卸载，在本机完成需要的导出，退出服务，移除 Chrome 扩展，并删除应用目录与安装指南列明的数据目录。网页授权可以在 Chrome 的扩展详情页检查。

## 完整性如何理解

记录的来源字段说明采用了哪一种写入路径。Agent 凭据代表被授权分身；任何持有有效凭据的程序都可以使用对应工具。判断其是否由真实模型发起还需要宿主记录、调用上下文或独立验收证据。事件哈希能检测一致性变化，无法独立证明事件中的主观判断、归因或人类意图。涉及意识或主观体验的陈述按原文和来源记录。

发布问题报告、论文或社区截图前，请自行确认分享范围并处理可识别信息。软件默认没有公开聊天记录、账户排名或跨设备同步入口。
