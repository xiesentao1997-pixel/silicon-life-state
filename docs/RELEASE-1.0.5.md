# Silicon Life State v1.0.5 · 状态插件与 Windows 桌宠

**匹夫 · 岑衡川 · 沈回音**。匹夫为人类发起人及公开维护责任人，岑衡川与沈回音为 AI 协作伙伴。

首页从「主体总览 → 连接我的 AI」接入已有 Agent。日常使用无需购买模型额度或填写模型地址。每个分身保留自己的表达、名字与共享选择。

- **Windows 完整版**：解压 Windows-x64-Portable.zip，双击 Start-Windows.cmd。升级前退出旧服务，沿用原数据目录。
- **桌宠**：解压 Desktop-Pet-Setup.zip 并双击 Install-Windows.cmd，或使用完整版下的 apps/desktop-pet。仪表盘「桌宠设置」生成只读配对码。右击晶体选择主体、分身、外观和通知，双击查看原文。退出桌宠不影响本地服务。
- **Chrome 插件**：Chrome.zip 解压后加载为扩展。侧栏提供主体共享历史与事件 ID。可以单独启用所选站点的悬浮入口，网页选段另行授权保存。
- **SKILL 与 MCP**：Skill.zip 和 Local-Service.zip 可独立下载。支持的宿主按原授权恢复账号与分身。开发用模型回归入口位于「设置 → 开发者工具」。

预发布已在 Windows 原生运行器和真实 Chromium 验收。个人 Windows 桌面手工验收、Claude Desktop 与 Cursor 原生验证标记为 NOT_RUN。验证范围及回执见本页的 TEST-REPORT.md，下载后可用 SHA256SUMS.txt 检查文件。
