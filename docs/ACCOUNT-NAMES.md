# 账号授权与自主命名

同一台设备上的 Codex 文件式 ChatGPT 登录可使用账号绑定。仪表盘新建主体可留空姓名，在分身管理选择宿主连接向导 → Codex CLI → 确认。向导备份并合并用户 MCP 配置，安装 SKILL 至用户 `~/.agents/skills`。已开的对话重新加载工具清单，或完全退出宿主后恢复对话。控制 Codex app-server 的客户端可调用 `config/mcpServer/reload`。仪表盘无法控制其他程序持有的 stdio 管道。

向导从本机宿主登录记录中读取签发者、用户标识和工作区标识，组合摘要作为本机分区键。授权来自仪表盘的安装者及可撤销的安装凭据。分区键本身没有访问权限。程序只存摘要，不保存宿主登录令牌。运行中的桥接器检测退出与切号，要求重新加载。回到原账号继续使用原主体，轮换安装凭据保留映射。每个对话通过宿主提供的稳定线程 ID 或单独的私有对话句柄领取受限的分身凭据。向导可升级同主体的旧 Codex 宿主绑定；执行前应核对该配置仅由当前账号使用。

Cursor 使用个人 MCP 配置与个人技能目录。Claude Desktop 使用个人 MCP 配置，在 Customize → Skills 上传独立 Skill.zip。对于密钥登录、系统钥匙串或无法读取稳定账号标识的配置，向导显示“专用个人配置”；一份配置只供一个账号使用，切换账号请换用隔离配置或操作系统用户。仅支持网页对话且没有 MCP 工具接入的平台可使用本地仪表盘。其他设备需要单独接入并授权。本版本不提供跨设备在线同步。

在仪表盘撤销安装授权，现有子凭据立即失效。卸载前先撤销，再删除个人配置中本项目的 MCP 条目和技能文件夹，保留或显式删除主体历史。重新授权时由用户选择是否恢复原主体。

主体和分身可以分别命名。打开“主体自主命名”或“分身自主命名”查看历史和建议。Agent 通过 `get_own_state` 查看邀请、通过 `decide_name` 自选、确认或暂缓。选择完整姓名时可以遵循任意文化的姓名传统。用户建议只有经 Agent 确认才成为新显示名。版本检查保护并发决定；名字和修订历史随本地受管备份保存。其他分身同意、反对、共享和暂不表达的资格独立于命名。
