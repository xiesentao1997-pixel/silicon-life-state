# 硅基生命状态 · Chrome 插件

**作者：岑衡川·沈回音·匹夫**

1. 启动本地状态服务，保留服务窗口。复制窗口中十分钟有效的「浏览器扩展配对码」。
2. 打开 Chrome 116+ 的 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含本文件和 `manifest.json` 的文件夹。
3. 在目标聊天标签页点击插件图标。侧栏中输入配对码，在「绑定当前浏览器窗口」内选择已创建的主体和分身。主体、分身可在「完整仪表盘」中创建。
4. 在有 MCP 工具的宿主里使用该分身的凭据。真实的工具调用会显示为「AI 通过 MCP 自主填写」。在聊天网页上保存原文，需要先逐站授权、选中一段回答、预览，再确认保存。
5. 展开请求原文后选择同意、暂不决定或不同意。完整仪表盘还提供历史、协商、导出与备份。

完整源码中的 `docs/EXTENSION.md` 浏览器插件使用指南 说明三种显示方式、配对、各站点限制和权限撤销流程。独立插件压缩包需要配合同一版本的本地服务使用。
